# Currency operation progress

Currency status `progress` is nullable. Only `confirmed` establishes100; idle is0. Active, failed, cancelled, superseded and invalid-identity states have no measured product denominator and return null. Clients must show the phase/message without substituting zero or a fabricated percentage. An observation timeout is not completion.

This intentionally removes the former fixed10/45/60/90 phase markers and100 on unsuccessful terminal states. Consumers are ours; no compatibility conversion is retained. The panel preserves status text, cancellation and exact operation observation. Product/destination counters and cross-domain progress architecture remain tracked in issue325.

Production verification: the installed public projection was invoked for10 representative states without creating or modifying a pricing job. Confirmed returned100 and the other nine returned null. PHP coordinator155 tests/2116 assertions and13 JavaScript checks passed. The ACF test fixture now supports the existing appendChild renderer; no ACF production renderer change was required. Authenticated user-session visual acceptance remains separate.
